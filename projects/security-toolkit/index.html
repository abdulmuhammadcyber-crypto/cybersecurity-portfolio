Quantum Resistant Password Hasher

Derives a salted hash using PBKDF2 with HMAC SHA 512. Symmetric hash primitives like SHA 512 are considered quantum resistant because Grover's algorithm only halves their effective security, unlike RSA or elliptic curve keys which Shor's algorithm breaks outright.

The output is a self describing string in the format pbkdf2$alg$iterations$salt$hash, encoded in Base64. A fresh 128 bit random salt is generated on every run, so hashing the same password twice produces different output. This is the intended behavior and defeats precomputed rainbow tables.

Verify a Password Against a Hash

Paste a stored hash string produced by the hasher, enter a candidate password, and confirm whether they match. Comparison is done in constant time to avoid timing side channels.
